# AI-Powered Vehicle Damage Assessment

## Project Description
This project uses AI to detect vehicle damage
and estimate repair costs and insurance claims.

## Technologies Used
- Python
- Flask
- YOLO11
- HTML
- CSS
- OpenCV
- PyTorch

## Features
- Vehicle damage detection
- Damage severity estimation
- Repair cost estimation
- Insurance claim estimation
- Duplicate image detection
- Claim ID generation
- Saved insurance claims

## Working Process
1. Upload vehicle image.
2. AI detects vehicle damage.
3. System identifies damaged parts.
4. Repair cost is estimated.
5. Insurance claim amount is calculated.
6. Claim details are saved.

- Number plate detection
